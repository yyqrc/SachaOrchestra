# Feedback（插件反馈）

## 功能

核实本次反馈并交给唯一的处理任务。入口授权和移交办法由下列合同定义。

## 输入与首查

1. 读取[入口合同](../../core/intake-contract.md#4-入口决定)的 Feedback 授权、[协调合同](../../core/coordination-contract.md#6-完成返回与偏差)的匹配与移交规则，以及当前适配器的反馈映射。当前入口已确定，反馈处理不加载工作流合同。
2. 围绕用户显式提交的反馈，核对插件现状及用户提供的任务、项目或原始证据。

## 动作顺序

1. 把具体反馈目标、用户提供的来源 reference 和调查结果交给协调合同判断。仅在协调合同要求用户消歧时读取[交互合同](../../core/human-interaction-contract.md)并询问能消除歧义的关键差异。
2. 通过当前适配器执行协调合同确定的匹配结果。成功、重复或无法移交时，分别按协调合同的条件交付或停止。

## 输出

按[交互合同](../../core/human-interaction-contract.md)说明已核实的事实和影响判断的缺口。确认处理目标后，给出目标任务链接或原生标识。
