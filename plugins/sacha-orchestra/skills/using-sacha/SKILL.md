# Using Sacha（智能入口）

先读[交互规则第 2 节](../../core/human-interaction-contract.md#2-信息顺序与可见性)和[入口规则第 2–4 节](../../core/intake-contract.md#2-最小加载)。处理显式技能、角色或其他专门请求时，再读入口规则第 4.1 节。

读取 Core 和适配器时，先按标题定位，只取当前动作所需章节的正文。读取正式技能时读完整正文。已读且仍适用的内容直接沿用。

- 准备方案、判断是否需要用户决定或补充授权时，读[交互规则第 3 节](../../core/human-interaction-contract.md#3-human-决定与对话同步)。需要等待时再读[第 4 节](../../core/human-interaction-contract.md#4-等待用户时的最后答复)。
- 需要安排持续探索、正式规划、正式实施、协调或独立评审时，先读[工作流第 2.2–3 节](../../core/workflow-contract.md#22-下游-skill-读取)确定当前步骤，再读该步骤的技能及其直接引用。
- 需要调用宿主协作工具、移交或恢复时，按[对应运行时适配器](../../README.md#运行规则)定位本次动作。
