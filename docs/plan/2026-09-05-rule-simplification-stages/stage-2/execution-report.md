- 新增真实 CLI 集成用例，在临时仓库与本地裸仓库中核对 not-required、可解析输出、commit、tag 和远端身份。

## 交付边界

本次只修改已批准的开发规则、发版指南、发布参数和对应测试。没有执行正式仓库的 commit、tag、网络 push、发版、安装或运行场景；测试内 Git 动作只发生在隔离临时仓库和本地裸仓库中。

当前证据证明源码、文档语义及隔离 CLI 行为，不证明实际网络发版耗时。后续真实发版可直接消费现有脚本分阶段计时，不以本轮测试耗时宣称发版已缩短到固定分钟数。

第三阶段的实际 Gate、research/grill、Spec、存档授权和生成器 Hash 机制尚未调整；候选继续保留在[共同决定记录](../decisions.md)。
