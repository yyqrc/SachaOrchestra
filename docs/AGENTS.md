# Sacha Orchestra 开发文档规则

> 本目录只供插件开发使用，不进入发布插件；发布可达和变更纪律沿用[根规则](../AGENTS.md)。

## 内容位置

- CONTEXT.md 定义开发专用共享术语，并索引插件内术语的负责文件、使用方和核验方法；不复制运行流程。
- integrations/** 解释能力提供方、项目绑定和开发接入，按当前任务只读具名指南及实际使用方。
- release.md 保存显式发布或安装的操作步骤；版本身份由 EVOLUTION.md 负责，机械动作由 scripts/release.py 执行。
- plan/** 保存具名任务的决定、实施规格、实施报告与评审记录；仅供该任务和恢复取证使用，状态或“已批准”字样不能替代当前定义与本次授权。

## 读取与维护

- 术语问题查询 CONTEXT.md 的相关项；只有入口、角色或高层流程确实相关时才读取 PLUGIN_DESIGN.md，其他任务按根规则查直接负责文件。
- 历史记录只在当前任务明确引用或当前来源不足以恢复时读取；不扫描计划目录寻找新规则，不改写冻结正文。仍会误导时加最短的历史说明及当前入口。
- 文档之间使用可达引用，同次修复移动或删除导致的直接链接；验证按根规则选择，不建立额外文档关卡。
- tests/runtime-scenarios 的任务、夹具和 oracle 属于测试输入与裁决材料，其执行流程见[场景说明](../tests/runtime-scenarios/README.md)。
