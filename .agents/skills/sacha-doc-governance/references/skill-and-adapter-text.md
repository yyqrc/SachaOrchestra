# 技能与适配器文本

## 使用范围

编写、迁移、精简或审查 Sacha 的技能（Skill）或适配器（Adapter）文本时使用本文。其他开发文档、核心合同（Core）和普通项目文档不加载。

## 技能

1. `description` 只说明何时使用和何时不使用，不复述正文流程或罗列能力清单。
2. 正文说明职责或功能、开始前要确认的事实、处理方法、输出和停止条件；需要扩大范围时写清条件。
3. 元数据提示词只提供自然入口，不复制正文步骤、内部路由或维护说明。
4. 章节名称服从实际语义；某项内容没有独立用途时不为满足固定结构增加章节。

## 适配器

1. 正文说明实现的核心合同、运行环境能力映射、调用参数、回退与恢复，以及实际运行证据能够证明什么。
2. 适配器的负责文件与产品边界沿用项目规则和对应核心合同，不在本文重新定义。

## 输出与停止

交付目标文本、唯一负责文件、实际使用方、保留要求和尚未验证的内容。改写会新增技能功能、适配器职责、产品入口、流程节点、授权或验收时停止，并按项目产品边界交给用户决定。
