# Skill 与 Adapter 文本

## 使用范围

编写、迁移、精简或审查 Sacha 的 Skill 或 Adapter 文本时使用本文。其他开发文档、Core 和普通项目文档不加载。

## Skill

1. `description` 只说明何时使用和何时不使用，不复述正文流程或罗列能力清单。
2. 正文说明职责或功能、输入与首查、动作顺序、输出、停止与禁止边界；需要扩大范围时写清条件。
3. 元数据提示词只提供自然入口，不复制正文步骤、内部路由或维护说明。
4. 章节名称服从实际语义；某项内容没有独立消费者时不为满足固定结构增加章节。

## Adapter

1. 正文说明实现的 Core 合同、Runtime 能力映射、调用参数、回退与恢复、Runtime 证据边界。
2. Adapter 的 Owner 与产品边界沿用项目规则和对应 Core，不在本文重新定义。

## 输出与停止

交付目标文本、唯一 Owner、直接消费者、保留命题和未验证边界。改写会新增 Skill 功能、Adapter 职责、产品入口、流程节点、授权或验收时停止，并按项目产品边界交给 Human 决定。
