# Sacha Runtime 场景

## 功能

按照 [Runtime 场景合同](../../../tests/runtime-scenarios/README.md)在隔离目录中运行一个具名任务包，保存直接证据并独立评估，确保一次结论只来自同一份源码、同一 Runtime 和同一次运行。

## 输入与首查

1. 要求一个现有场景包，或者用户已确认的新场景目标、目标 Runtime 和需要取得的证据；普通静态检查不使用本 Skill。
2. 完整读取 Runtime 场景合同、目标 `task.md` 和测试夹具（`fixture/`）；执行者不得读取 `oracle.md`，独立评估者不得接收实现者的隐藏预期。
3. 核对当前源码或已安装插件来源、目标 Adapter、运行授权和任务上下文。需要用户创建全新主任务、安装、外部账号、设备或其他高影响前置时先取得明确授权。

## 动作顺序

1. 在工作区 `.temp/runtime-scenarios/<run-id>/<case-id>/` 创建唯一隔离目录，复制测试夹具、将任务改为中性名称并注入场景合同要求的工作区规则；不在源任务包内运行。
2. 按任务包验收选择不携带父历史的委派 Agent，或使用用户授权的全新主任务。执行者只取得中性任务、隔离目录、目标 Runtime 正式入口和必需规则，不取得包名、`oracle.md`、开发顶层设计或结论提示。
3. 每次运行单独保存准确的源码或安装身份、Runtime/Adapter、首次原生调用、返回标识、工作区改动、验证器原始输出、用户问答和必要的任务关系。失败重跑使用新的隔离目录，不拼接不同运行的轨迹或结果。
4. 执行结束后创建未参与实现的独立评估者，只提供 `oracle.md`、目标 Adapter、直接记录、最终工作区和验证器输出；按 `pass | drift | blocked` 判断第一处偏移及其证据。
5. 任务创建、安装后发现、Runtime 调用和外部状态分别报告。未安装的源码运行只能标记 `source-scenario`；缺少必要原生记录时判 `blocked`，不以自报补齐。

## 输出

- 返回场景、Runtime、源码或安装身份、隔离目录、直接证据、验证结果、独立结论和尚未验证的部分。
- 保留仍供复核的本次证据；只清理本任务创建且已确认不再需要的临时文件。

## 停止与禁止边界

- 不预读或向执行者泄露 `oracle.md`，不用测试夹具字符串、校验器、静态源码或执行者总结替代 Runtime 行为。
- 不自行安装插件、创建全新用户任务、修改用户配置、调用外部服务或扩大场景授权。
- 新场景必须来自真实失败模式或待验证的流程变化，不为覆盖节点数量拼装任务。
