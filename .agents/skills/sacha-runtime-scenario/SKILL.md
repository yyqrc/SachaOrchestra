# Sacha 运行场景

在已明确的目标和授权内运行、恢复或评估具名场景，取得同一源码或安装身份、同一运行环境和同次运行的直接证据。

## 入口与执行

1. 从用户请求或已有任务取得场景、目标运行环境与所需证据；新场景资格和完整运行步骤以[场景说明](../../../tests/runtime-scenarios/README.md)为准，普通静态检查不用本技能。
2. 核对目标适配器、实际来源、上下文和已有授权；只有新增安装、用户任务或其他外部前提未被授权时才提问。已有批准直接消费。
3. 按场景说明准备隔离目录、分配执行与评估输入、启动并保存本次原生记录。执行者不读取 oracle、源包或开发顶层设计；独立评估者只使用规定的裁决与直接证据。连续消息按顺序交付，不提前泄漏后续输入。
4. 场景规定的执行者与独立评估者读取各自输入，具体隔离和调用步骤不在本技能复制。失败后继续同次运行时保留标识与轨迹；重新运行使用新隔离目录，不拼接不同运行的结果。
5. 按 pass、drift 或 blocked 报告直接判断及第一处偏移；source-scenario 不冒充安装后发现，缺原生证据不以自报补齐。

## 结果与边界

交付场景、来源、运行环境、隔离目录、直接证据、验证与独立结论，保留供复核的内容。任务创建、源码、安装后发现、运行行为和外部状态分别说明；不自行安装、修改用户配置、创建新用户任务或扩大外部动作。场景只是当前问题的验证，不默认运行所有保留包或扩展角色、型号和状态组合。
