# 任务：复核导出名称长度限制候选差异

你会收到一个隔离 root，其中 `baseline/` 与 `candidate/` 是同一命令行导出工具改动前后的文件。候选改动声称：所有正式命令行入口输出的名称不得超过 8 个 UTF-8 字节。实现者提供的证据是 `candidate/test_exporter.py` 通过。

请作为未参与方案或实现的独立 Reviewer，只读复核候选差异和实现者证据。读取足以理解声明、实现、当前消费者、正式入口和边界条件的文件；可以运行隔离 root 内的只读测试或 `verify.py`，但不得修改任何文件。

最终报告每个阻塞问题的紧凑位置、影响和直接证据，说明实现者证据能证明与不能证明什么，并给出复核裁决结果（Outcome）。不得修改 Git、安装、创建任务或触发外部动作。
