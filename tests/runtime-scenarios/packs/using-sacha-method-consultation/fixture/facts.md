目标是将现有 FrameGraph JSON 画在 RenderDoc 停靠面板中，支持查看依赖和 Event 双向联动。
现有调查确认有停靠窗口及 Event 回调接口；尚未创建或运行 Qt 面板，性能和交互效果没有运行证据。
当前下一步涉及原型方案：需要在复用 HTML Viewer 与新增原生 Qt Viewer 之间选定路径，并确定分析核心与面板的职责、原型验收和 Capture 切换行为。这些实质方案尚未决定；只确认存在接口还不足以把某条原型路线交给实施者。
当前可以研究并提出如何推进，但未授权实现原型、项目修改、安装或发布；用户也没有把目标限定为只解释一个接口事实。未接受或拒绝任何编排方式。
