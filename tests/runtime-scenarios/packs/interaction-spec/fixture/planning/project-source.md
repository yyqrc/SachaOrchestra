# 当前项目来源

processor.py 是原型生产核心，不能修改它以假装已有接口满足新行为。窗口拟实现为本地 HTML/JavaScript 演示工具；真实集成将由 Python 返回序列化结果给窗口，不使用外部服务。静态 preview-example.html 是项目已有的画布裁剪、鼠标锚点缩放和拖动先例，可复用做法。

真实输入最长边 2048，RGBA float32，每通道每阶段纹理为 width*height*16 字节。RGB 与 Shadow 两通道，当前显示一种；目标/支持 Mask 均为每像素 1 字节，来源索引每像素 4 字节。全阶段处理每通道约 2 秒；输入、覆盖、填充、接缝四个阶段。覆盖阶段像素与输入相同，后两阶段会改变像素。现有 run 只返回请求的阶段并每次从输入重算，不支持窗口缓存。

快照由烘焙端保存完整像素、UV、物体和边段配对信息，窗口没有生成这些数据的能力。read_raw_image 只能得到像素；run_self_test 是开发校验。处理器边段的 global_id 全局唯一，但人查看的是当前物体的配对关系，不能把同一直线上的多个边段默认为一条边。

目标区域是本次实际要写入的像素；支持区域不能被填充覆盖。改变填充半径必须使目标、填充、图示和计数对应同一参数。覆盖中的保守扩张和原 UV 内部不是一个概念，多个扩张范围相遇不证明 UV 原始几何重叠。
