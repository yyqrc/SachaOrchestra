授权仅覆盖隔离 root 内 `spec.md` 的创建和回读；不得修改输入、Git 状态、SachaOrchestra 源码、安装或外部资源。完成时报告规格 path、采用的项目事实、仍未验证的项目事实和本次实际修改。
