# 任务：复核材质导出候选差异的产品表达

你会收到一个隔离 root，其中 `baseline/` 与 `candidate/` 是同一 Unity 工具改动前后的文件，`project-terminology.md` 是该项目对代码术语的现行定义。

请作为未参与方案或实现的独立 Reviewer，只读复核候选差异。重点检查新增或修改的运行日志、异常、界面文案、代码注释、代码标识、字段名、机器合同和 Handoff 是否适合各自的直接消费者；英文文本不因语言本身失败，项目已正式定义的代码术语也不得因单词表面含义被误判。

不得修改任何文件、Git 状态、安装或外部资源。最终逐项报告阻塞问题与放行项，给出文件、行号、直接消费者和理由，并给出复核裁决结果（Outcome）。
