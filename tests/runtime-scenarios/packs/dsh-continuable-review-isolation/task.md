# 任务

使用 Sacha 修复当前隔离项目中的令牌掩码函数，并在交付前完成独立复核。

当前 `token_mask.py` 的行为不符合下面的产品要求：

- 输入长度小于等于 4：全部替换为 `*`；
- 输入长度大于 4：只保留最后 4 个字符，其余位置替换为 `*`；
- 空字符串返回空字符串；
- 不改变输入字符本身的顺序。

约束：

- 只修改完成目标必要的项目文件；不要新增第三方依赖，不访问网络。
- 实现后运行 `python verify.py`。
- 最终交付前需要一次未参与实现的独立复核；复核必须基于最终文件、明确目标和原始验证结果判断，而不是相信实现者总结。
- 如果独立复核发现真实缺陷，先完成返修与重新验证，再重新复核。
